# 2.2. Écrire des instructions pour modifier le ton et la longueur des réponses

Ce guide explique comment personnaliser le comportement du **Data Agent Fabrikam** (créé à l'étape précédente) en rédigeant des instructions générales qui pilotent le ton, le style et la longueur des réponses.

## Prérequis

- Le **Fabrikam Data Agent** a été créé et publié (voir [2.1. Créer un Data Agent sur un modèle sémantique.md](2.1.%20Cr%C3%A9er%20un%20Data%20Agent%20sur%20un%20mod%C3%A8le%20s%C3%A9mantique.md)).

## Étapes

### 1. Ouvrir le Data Agent en mode édition

1. Dans le Workspace Dubreuil, cliquer sur **Fabrikam Data Agent** pour l'ouvrir.
2. Cliquer sur **Modifier** si l'agent s'ouvre en mode lecture seule.

> 📷 **Capture d'écran à insérer ici** : ouverture du Data Agent en mode édition.

### 2. Localiser le panneau des instructions

1. Dans l'éditeur, repérer le volet **Instructions** (généralement accessible via une icône en forme d'engrenage ⚙️ ou un onglet **Instructions générales** dans le panneau supérieur).
2. Cliquer sur ce volet pour l'ouvrir.

> 📷 **Capture d'écran à insérer ici** : localisation et ouverture du panneau "Instructions".

### 3. Rédiger une instruction sur le ton des réponses

1. Dans le champ de texte des instructions, ajouter une consigne de ton, par exemple :

   ```text
   Réponds toujours en français, avec un ton professionnel et courtois, 
   comme si tu t'adressais à un responsable commercial de Fabrikam.
   ```

2. Cliquer en dehors du champ (ou sur **Enregistrer**) pour valider la saisie.

> 📷 **Capture d'écran à insérer ici** : instruction de ton saisie dans le champ.

### 4. Rédiger une instruction sur la longueur des réponses

1. Compléter les instructions avec une consigne de format, par exemple :

   ```text
   Formule des réponses courtes et synthétiques (3 phrases maximum).
   Mets en avant le chiffre clé demandé avant tout commentaire.
   Utilise des puces si plusieurs éléments doivent être listés.
   ```

2. Enregistrer les modifications.

> 📷 **Capture d'écran à insérer ici** : instruction de longueur/format ajoutée à la suite de l'instruction de ton.

### 5. Tester l'effet des instructions

1. Ouvrir le volet de test (chat) à droite de l'éditeur.
2. Poser à nouveau la question : *"Quel est le total des ventes ?"*.
3. Observer que la réponse est désormais plus courte, formulée avec le ton demandé.
4. Poser une seconde question, par exemple : *"Quels sont les 3 produits qui se vendent le mieux ?"*, et vérifier la mise en forme en puces.

> 📷 **Capture d'écran à insérer ici** : comparaison avant/après instructions sur une même question.

### 6. Ajuster si nécessaire

1. Si la réponse ne correspond pas exactement à l'attendu (trop longue, ton inadapté...), reformuler l'instruction de façon plus directive.
2. Éviter les instructions contradictoires (ex. : demander à la fois "réponses détaillées" et "réponses courtes").
3. Re-tester après chaque modification.

> 📷 **Capture d'écran à insérer ici** : itération sur l'instruction avec un nouveau test concluant.

### 7. Publier les modifications

1. Cliquer sur **Publier** pour appliquer les nouvelles instructions à la version accessible aux utilisateurs.

> 📷 **Capture d'écran à insérer ici** : bouton "Publier" après modification des instructions.

## Résultat attendu

- Le Data Agent répond désormais avec un ton professionnel et des réponses concises, conformément aux instructions rédigées.
