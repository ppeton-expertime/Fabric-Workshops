# 0.1. Récupération du fichier Fabrikam.pbix et chargement dans le Workspace Fabric

Ce guide explique comment récupérer le fichier **Fabrikam Company Sales Report.pbix** depuis GitHub et le charger dans un Workspace Microsoft Fabric.

## 1. Télécharger le fichier depuis GitHub

1. Ouvrir le lien du fichier sur GitHub :<br>
   [Fabrikam Company Sales Report.pbix](https://github.com/microsoft/FabConATL26CWYDWorkshop/blob/main/Fabrikam%20Company%20Sales%20Report.pbix)
2. GitHub affiche une page de prévisualisation (le fichier `.pbix` n'est pas lisible directement dans le navigateur).
3. Cliquer sur le bouton **Download raw file** (icône de téléchargement, en haut à droite de la prévisualisation).
4. Le fichier **Fabrikam Company Sales Report.pbix** est téléchargé dans votre dossier de téléchargements local.

> **Astuce :** si le bouton de téléchargement n'est pas visible, ajouter `?raw=true` à la fin de l'URL ou utiliser le lien direct : `https://raw.githubusercontent.com/microsoft/FabConATL26CWYDWorkshop/main/Fabrikam%20Company%20Sales%20Report.pbix`

## 2. Charger le fichier dans le Workspace Fabric

1. Se connecter à [Microsoft Fabric](https://app.fabric.microsoft.com).
2. Ouvrir le **Workspace Dubreuil** (ou le workspace cible de la formation).
3. Cliquer sur **Importer** (ou **New** > **Import** selon la vue) puis sélectionner **Power BI report** (ou glisser-déposer le fichier).
4. Sélectionner le fichier **Fabrikam Company Sales Report.pbix** téléchargé à l'étape précédente.
5. Patienter pendant l'import : Fabric crée automatiquement le **rapport** et le **modèle sémantique** associés dans le workspace.
6. Vérifier que les deux éléments (rapport + modèle sémantique) apparaissent bien dans la liste des éléments du workspace.

Le fichier est maintenant prêt à être utilisé pour les exercices Copilot pour Power BI et Data Agent.
