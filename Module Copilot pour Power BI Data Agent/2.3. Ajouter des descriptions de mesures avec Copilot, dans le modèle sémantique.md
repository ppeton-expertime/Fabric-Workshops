# 2.3. Ajouter des descriptions de mesures avec Copilot, dans le modèle sémantique

Ce guide explique comment utiliser **Copilot** pour générer automatiquement des descriptions de mesures dans le modèle sémantique Fabrikam, afin d'améliorer la compréhension du contexte métier par le Data Agent.

## Prérequis

- Le modèle sémantique **Fabrikam Company Sales Report** est disponible dans le Workspace Dubreuil.
- Vous disposez des droits d'édition sur le modèle sémantique.
- Copilot pour Power BI est activé pour le tenant/capacité.

## Pourquoi cette étape est importante

Le Data Agent s'appuie sur les métadonnées du modèle sémantique (noms de tables, de colonnes, de mesures, et **leurs descriptions**) pour comprendre le sens métier des données. Une mesure sans description (ex. `Total Sales`) est moins bien interprétée qu'une mesure documentée expliquant precisément son calcul et son usage.

## Étapes

### 1. Ouvrir la vue de modélisation du modèle sémantique

1. Dans le Workspace Dubreuil, cliquer sur les **"..."** à côté du modèle sémantique **Fabrikam Company Sales Report**.
2. Sélectionner **Ouvrir la vue de données** (ou **Modifier** selon l'interface), afin d'accéder à l'éditeur de modèle sémantique en ligne.

> 📷 **Capture d'écran à insérer ici** : menu contextuel du modèle sémantique avec l'option d'édition.

### 2. Basculer sur la vue "Modèle"

1. Dans l'éditeur, cliquer sur l'onglet **Modèle** (vue diagramme des tables et relations).
2. Repérer la table contenant les mesures principales (ex. `Sales` ou `_Measures`).

> 📷 **Capture d'écran à insérer ici** : vue Modèle avec le diagramme des tables.

### 3. Sélectionner une mesure sans description

1. Développer la table de mesures et cliquer sur une mesure, par exemple `Total Sales`.
2. Dans le volet **Propriétés** (à droite), repérer le champ **Description**, actuellement vide.

> 📷 **Capture d'écran à insérer ici** : sélection de la mesure `Total Sales` et volet Propriétés avec le champ Description vide.

### 4. Générer la description avec Copilot

1. Cliquer sur l'icône **Copilot** (étincelle ✨) à côté du champ **Description**.
2. Copilot analyse la formule DAX de la mesure et propose une description en langage naturel.
3. Patienter quelques secondes le temps de la génération.

> 📷 **Capture d'écran à insérer ici** : clic sur l'icône Copilot et affichage de la proposition de description.

### 5. Relire et ajuster la description proposée

1. Lire attentivement la description générée.
2. La compléter si besoin avec des précisions métier propres à Fabrikam (unité, périmètre, filtre implicite...).
3. Exemple de description finale :

   ```text
   Somme du chiffre d'affaires total réalisé sur l'ensemble des commandes, 
   exprimé en euros, hors taxes. Utilisée comme indicateur clé de performance commerciale.
   ```

4. Valider en cliquant en dehors du champ ou sur **Enregistrer**.

> 📷 **Capture d'écran à insérer ici** : description finale relue/ajustée et validée.

### 6. Répéter l'opération pour les mesures clés

1. Répéter les étapes 3 à 5 pour les autres mesures importantes du modèle (ex. `Total Profit`, `Profit Margin`, `Quantity Sold`, `Average Order Value`...).
2. Prioriser les mesures qui seront très probablement interrogées via le Data Agent.

> 📷 **Capture d'écran à insérer ici** : liste des mesures principales avec leurs descriptions renseignées.

### 7. Enregistrer les modifications du modèle sémantique

1. Cliquer sur **Enregistrer** (ou l'enregistrement automatique est confirmé par une notification).
2. Vérifier qu'aucune erreur de validation n'apparaît.

> 📷 **Capture d'écran à insérer ici** : confirmation d'enregistrement du modèle sémantique.

### 8. Vérifier la prise en compte par le Data Agent

1. Retourner sur le **Fabrikam Data Agent**.
2. Dans le volet de test, poser une question utilisant une des mesures récemment documentées, par exemple : *"Quelle est la marge de profit moyenne ?"*.
3. Vérifier que la réponse est cohérente et bien contextualisée.

> 📷 **Capture d'écran à insérer ici** : test du Data Agent sur une mesure fraîchement documentée.

## Résultat attendu

- Les principales mesures du modèle sémantique Fabrikam disposent désormais d'une description claire générée avec Copilot.
- Le Data Agent exploite ces descriptions pour mieux comprendre et répondre aux questions métier.
