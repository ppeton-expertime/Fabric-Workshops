# 2.4. Optimiser les instructions pour bien répondre sur des questions de contexte métier

Ce guide explique comment affiner les instructions du **Fabrikam Data Agent** afin qu'il interprète correctement les questions impliquant un contexte métier implicite, notamment l'axe du temps (*"l'année dernière"*, *"le mois prochain"*, *"le trimestre en cours"*...).

## Prérequis

- Le Fabrikam Data Agent a été créé, ses instructions de ton/longueur sont en place (voir [2.2. Écrire des instructions pour modifier le ton et la longueur des réponses.md](2.2.%20%C3%89crire%20des%20instructions%20pour%20modifier%20le%20ton%20et%20la%20longueur%20des%20r%C3%A9ponses.md)).
- Les descriptions de mesures ont été ajoutées (voir [2.3. Ajouter des descriptions de mesures avec Copilot, dans le modèle sémantique.md](2.3.%20Ajouter%20des%20descriptions%20de%20mesures%20avec%20Copilot%2C%20dans%20le%20mod%C3%A8le%20s%C3%A9mantique.md)).

## Pourquoi cette étape est importante

Sans précision, un Data Agent peut mal interpréter des expressions temporelles relatives (par rapport à quelle date ? quel calendrier fiscal ?) ou des notions métier propres à l'entreprise (région commerciale, segment client...). Documenter ce contexte dans les instructions permet d'obtenir des réponses fiables et reproductibles.

## Étapes

### 1. Identifier les questions problématiques

1. Dans le volet de test du Data Agent, poser une question contenant une référence temporelle relative, par exemple : *"Quelles ont été les ventes de l'année dernière ?"*.
2. Observer la réponse : vérifier si le Data Agent a bien identifié la bonne période (ex. année civile précédente vs année fiscale).
3. Faire de même avec : *"Quelles sont les ventes prévues le mois prochain ?"* ou *"Comment évoluent les ventes ce trimestre ?"*.
4. Noter les cas où l'interprétation est incorrecte ou ambiguë.

### 2. Clarifier la définition du calendrier dans les instructions

1. Retourner dans le panneau **Instructions** du Data Agent (voir étape 2 du guide [2.2](2.2.%20%C3%89crire%20des%20instructions%20pour%20modifier%20le%20ton%20et%20la%20longueur%20des%20r%C3%A9ponses.md)).
2. Ajouter une section décrivant le calendrier de référence, par exemple :

   ```text
   Contexte temporel :
   - L'année fiscale de Fabrikam correspond à l'année civile (janvier à décembre).
   - "L'année dernière" fait référence à l'année civile précédant la date du jour.
   - "Le mois prochain" fait référence au mois suivant le mois en cours.
   - Utilise toujours la colonne Date[Année] et Date[Mois] de la table Date pour ces calculs.
   ```

3. Enregistrer les modifications.

### 3. Documenter les notions métier spécifiques

1. Ajouter, dans les instructions, la définition des notions métier ambiguës propres à Fabrikam, par exemple :

   ```text
   Contexte métier :
   - Une "région" correspond à la colonne Region[Nom région].
   - Un "gros client" désigne un client dont le total des achats dépasse 50 000 €.
   - Le "chiffre d'affaires" correspond toujours à la mesure Total Sales (hors taxes).
   ```

2. Enregistrer les modifications.

### 4. Ajouter des exemples de questions/réponses (few-shot) si l'interface le permet

1. Si le Data Agent propose une section **Exemples de questions** (ou équivalent), ajouter 2 à 3 exemples représentatifs :
   - Question : *"Quelles ont été les ventes de l'année dernière ?"*
   - Réponse attendue : rappel de l'année concernée + valeur chiffrée.
2. Ces exemples aident le Data Agent à généraliser le bon comportement sur des questions similaires.

### 5. Re-tester les questions initiales

1. Reposer exactement les mêmes questions qu'à l'étape 1 dans le volet de test.
2. Vérifier que :
   - La bonne période est identifiée (année, mois, trimestre).
   - Les notions métier (région, gros client, chiffre d'affaires...) sont correctement appliquées.
3. Comparer les réponses avant/après optimisation.

### 6. Itérer sur les cas restants

1. Si certaines questions restent mal interprétées, reformuler les instructions de façon plus explicite (éviter les formulations vagues).
2. Tester des variantes de formulation (ex. *"l'an passé"*, *"l'année précédente"*) pour vérifier la robustesse.
3. Répéter jusqu'à obtenir des réponses stables et correctes.

### 7. Publier la version optimisée

1. Cliquer sur **Publier** pour rendre les instructions optimisées disponibles à tous les utilisateurs du Data Agent.

## Résultat attendu

- Le Data Agent répond correctement aux questions contenant des références temporelles relatives et des notions métier spécifiques à Fabrikam.
